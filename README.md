# Identity & Access Management (IAM) Labs - Abrielle Stokes
This repository is a living record of my hands-on IAM work. Each lab documents a real configuration, a real environment, and a real skill — not just theory. I built this to demonstrate what I can actually do, not just what I've studied.

My background spans identity provider implementation, large-scale user onboarding, and ServiceNow administration. IAM is the natural evolution of that work — moving from managing access processes to engineering and securing the identity systems that power them.

I'm actively building toward the Microsoft SC-300 (Identity and Access Administrator) certification, with a longer-term path into cloud security and identity governance.
